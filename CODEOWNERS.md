# CODEOWNERS
#
# Defines who is automatically requested as reviewer when a pull request
# changes certain files or folders.
#
# Format:   <path>   <@github-username>
# The LAST matching rule wins, so put general rules first and specific ones after.
#
# Examples (to be updated when areas and leads are decided):
#
#   *              @lead-default        # everything not matched below
#   /frontend/     @lead-frontend       # frontend area
#   /backend/      @lead-backend        # backend area
#   /database/     @lead-database       # database scripts and migrations
#
# Note: with the GitHub Free plan, on private repositories the review
# is requested automatically but cannot be made mandatory.
